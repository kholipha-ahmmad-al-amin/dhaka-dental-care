# Dhaka Dental Care — Official Website (Demo)

A fictional dental clinic website for Dhaka, built as a single-page site with:
- Scroll animations (reveal, progress bar, counters, marquee)
- Scroll-driven 3D animation (Three.js tooth in the hero, 3D tilt on the Smile Journey stage)
- Services, pricing / buy-a-package, fictional dentists, reviews, and a demo booking form

**All content is fictional** — dentists, prices, address, phone number and reviews are demo placeholders. Replace them with real details before showing clients as a real business.

## Deploy to GitHub Pages (2 minutes)

1. On github.com, create a new **public** repository named `dhaka-dental-care` (do not add a README, it will conflict).
2. Upload `index.html` to the root of that repository (or push this folder).
3. Go to **Settings → Pages → Build and deployment → Source: Deploy from a branch**, select `main` / root, Save.
4. Your site will be live at: `https://<your-username>.github.io/dhaka-dental-care/`

## Local preview
Open `index.html` in any browser, or run: `python3 -m http.server 8000` in this folder and visit http://localhost:8000
